# 🥣 BeautifulSoup (bs4) — Asosiy Tushunchalar

Veb-saytlardan ma'lumot yig'ish (scraping) bo'yicha o'quv namunalari: matn, rasm va video yuklab olish.

---

## ✨ Imkoniyatlar

- 📝 **Matn yig'ish** (`text_downloading.py`)
- 🖼 **Rasm yuklab olish** (`image_downloading.py`)
- 🎬 **Video yuklab olish** (`video_downloading.py`)
- 🎓 **O'quv maqsadi:** bs4 asoslari

---

## 🛠 Texnologiyalar

| Texnologiya | Maqsad |
|---|---|
| **Python 3.10+** | Asosiy til |
| **requests** | HTTP so'rovlar |
| **BeautifulSoup (bs4)** | HTML tahlil |

---

## ⚙️ O'rnatish

```bash
git clone https://github.com/dastonbek8747/BeautifulSoup-bs4-basic-concepts.git
cd BeautifulSoup-bs4-basic-concepts
pip install -r requirements.txt
```

```bash
python text_downloading.py
python image_downloading.py
python video_downloading.py
```
