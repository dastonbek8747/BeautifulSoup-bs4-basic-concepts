# BeautifulSoup Web Scraping Basics

> Three small scripts that download text, images and videos from a web page with BeautifulSoup.

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)


## What Is Inside

| File | What it does |
|---|---|
| `text_downloading.py` | Extracts text from a page. |
| `image_downloading.py` | Downloads all images from a page. |
| `video_downloading.py` | Finds and downloads video sources. |

## Quick Start

```bash
git clone https://github.com/dastonbek8747/beautifulsoup-web-scraping.git
cd beautifulsoup-web-scraping
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python text_downloading.py
```

## Tech Stack

- BeautifulSoup (bs4)
- requests

## Note

Respect each site's terms of service and `robots.txt` when scraping.
